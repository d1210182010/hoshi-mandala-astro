# 星曼荼羅 (Hoshi Mandala)

這是一個結合**密教美術**與**現代天文學**的互動視覺化專案。它嘗試探索古老的宗教宇宙觀與真實物理宇宙之間的關聯，將平面的《星曼荼羅》還原為立體的太陽系動態。

🔗 **Live Demo**: [https://d1210182010.github.io/hoshi-mandala-astro/](https://d1210182010.github.io/hoshi-mandala-astro/)

---

## 🌌 這是什麼？

在密教（Esoteric Buddhism）中，「星曼荼羅」是一幅描繪眾星神格化的壇場圖。古人相信天體運行主宰著國家的命運與個人的禍福。

這個專案提供了兩種視角來觀察同一個宇宙：

1.  **2D 曼荼羅視角 (Mandala Mode)**：
    *   這是**「理想的宗教宇宙」**。
    *   所有星體依據經典（如《宿曜經》）排列成完美的幾何圓形。
    *   位置象徵著神格的位階與功能，而非實際的天空位置。

2.  **3D 天文視角 (Cosmos Mode)**：
    *   這是**「真實的物理宇宙」**。
    *   依據現代天文演算法（Swiss Ephemeris 精度），計算星體在太陽系中的真實座標。
    *   你可以看到這些「星神」在太空中實際運行的軌跡。

## 🎮 如何使用

介面設計簡潔，讓使用者能專注於視覺體驗：

### 1. 切換維度
點擊右上角的按鈕切換模式：
*   **2D 曼荼羅**：進入幾何對稱的平面圖，適合觀察星宿的傳統佈局。
*   **3D 天文**：進入立體空間，可自由旋轉、縮放視角（拖曳滑鼠或手指），觀察星體間的距離與相對位置。

### 2. 時間旅行
畫面下方的 **時間軸 (Timeline)** 允許你穿越時空：
*   **播放/暫停**：觀看星體的公轉運動。
*   **拖曳滑桿**：快速跳轉到過去或未來（預設範圍：1990 - 2099 年）。
*   *觀察重點*：試著在 3D 模式下拖曳時間，你會看到「歲星（木星）」大約 12 年繞行一圈，這正是「太歲」信仰的天文基礎。

### 3. 星體資訊
點擊畫面上的任何梵字或星體圖示，右下角會顯示該星宿的詳細資訊：
*   **漢譯名稱**（如：貪狼、虛宿、日曜）
*   **梵文種子字**（Sanskrit Bīja）
*   **所屬群組**

## 🔮 理解星曼荼羅的結構

曼荼羅的佈局由內而外分為數層，代表不同的宇宙力量：

### 1. 中央：一字金輪 (Ichiji Kinrin)
*   **位置**：圓心。
*   **意義**：眾星之王，象徵北極星或大日如來的化身，統攝所有星宿。
*   *在 3D 模式中，它化為巨大的背景籠罩整個太陽系。*

### 2. 第一層：北斗與九曜
*   **北斗七星 (Big Dipper)**：掌管人的壽命與死亡。位於上方半圓。
*   **九曜 (Navagraha)**：即日月金木水火土，加上羅睺 (Rahu) 與計都 (Ketu)。掌管人的吉凶禍福。位於下方半圓。
    *   *天文冷知識*：羅睺與計都其實不是實體星球，而是月球軌道的「升交點」與「降交點」（發生日食月食的地方），但在古印度天文學中被視為隱形的星體。

### 3. 第二層：十二宮 (Zodiac)
*   **意義**：源自西方的黃道十二星座（牡羊、金牛...），代表太陽每年的運行路徑。
*   **功能**：象徵時間的循環與季節的變化。

### 4. 第三層：二十八宿 (Lunar Mansions)
*   **意義**：月球在一個月中每天停留的位置（月站）。
*   **功能**：將天空劃分為 28 個區域，作為觀測日月五星運行的座標背景。

## 🛠️ 技術說明

本專案使用現代網頁圖學技術構建：

*   **核心引擎**: React 18, TypeScript
*   **3D 渲染**: Three.js (@react-three/fiber)
*   **天文計算**: `astronomy-engine` (計算即時星曆)
*   **動畫**: Framer Motion (介面), Vector3 Interpolation (2D/3D 無縫轉場)
*   **字體渲染**: 使用 SDF 或高解析度 Canvas 縮放技術，確保梵字在 3D 空間縮放時保持清晰。
